## W5049. Storage Facility Daily Operations, Housekeeping & Maintenance Management

| Field | Detail |
|---|---|
| **Trigger** | Daily site open/close; PM cycle; reactive maintenance request |
| **Frequency** | Daily operations + scheduled PM |
| **Volume** | ~50 storage sites × daily ops + PM backlog |
| **Owner** | Property Manager (Storage) / Facilities (VS-138) |
| **Participants** | Facilities (VS-138), Property Manager, HSE (VS-24), Security (VS-23), vendor maintenance |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Run daily site operations: open/close, lighting/HVAC/climate-control checks (climate units), corridor/elevator/lift function, signage, and the daily walk-through | Property Mgr / Facilities | Property Manager | Daily |
| 2 | Execute housekeeping & PM: cleaning, pest control (links VS-138), door/lock/roller-door lubrication, lighting replacement, and the scheduled PM cycle on facility assets | Facilities / Vendor | Property Manager | Per PM cycle |
| 3 | Manage reactive maintenance: tenant-reported defects, work-order creation, vendor dispatch, and closure verification feeding facilities analytics (VS-138) | Facilities / Property Mgr | Property Manager | Per request |

### System Touchpoints
- IFM/CMMS work-order (VS-138); storage PMS site ops; HSE (VS-24); asset/fixed-asset (VS-35); vendor/maintenance procurement (VS-34)

### Pain Points / Risks
- **Climate-control-failure risk**: HVAC failure in climate units → tenant goods damage (mold/warp); mitigated by temp/humidity monitoring + rapid response
- **Deferred-PM risk**: Deferred door/lock PM → security gaps; mitigated by PM schedule adherence
- **Pest risk**: Infestation → tenant complaints/claims; mitigated by integrated pest management (VS-138)

### Automation Opportunity
- IoT temp/humidity monitoring → auto-alert; Oracle eAM PM auto-generation (fit-gap F5); tenant self-service maintenance request

### Controls
- CTL-754 (ensure controlled execution — Storage Operations, Maintenance, Safety & Analytics (PA-174.3).)
- CTL-754: PM schedule adherence (VS-138); climate-unit temp monitored; work-order closure verified

### Time Estimate
- ~2–4 hours/site/day operations; ~continuous PM backlog

### Cross-references
- links to VS-138 (IFM), VS-35 (assets), VS-24 (HSE), VS-34 (procurement); W5037 (facility design), W5052 (fire/life-safety)

| **Volume** | ~all move-ins + ~periodic per site |
| **Owner** | Property Manager (Storage) / HSE (VS-24) |
| **Participants** | HSE (VS-24), Property Manager, Legal (VS-100), Security (VS-23), Compliance (VS-22) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Communicate prohibited-goods policy: at lease execution (W5038/W5042), brief the tenant on the prohibited list (flammables, explosives, fuels/LPG, perishables, illegal items, hazardous waste) and the inspection right | Property Mgr / HSE | Property Manager | Per move-in |

- **Legal/liability risk**: Illegal items on premises; mitigated by inspection right + authority reporting
- **Hazardous-disposal risk**: Improper handling of discovered hazardous goods (DENR); mitigated by VS-73/VS-114 protocol

### Automation Opportunity
- Prohibited-goods acknowledgment e-capture; inspection scheduling; AI-video anomaly flagging on visible items

### Controls
- CTL-99 (ensure storage lien & prohibited-goods control.)
- CTL-754: prohibited-goods policy in lease & acknowledged (W5038); inspection right exercised; hazardous disposal per VS-73/VS-114

### Time Estimate
- ~15–30 min/move-in briefing; periodic inspection ~per site cycle

### Cross-references
