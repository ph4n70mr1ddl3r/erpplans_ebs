## W4809. Locker Preventive Maintenance, Cleaning & Hardware Health

| Field | Detail |
|---|---|
| **Trigger** | Calendar interval; platform health alert (W4807); post-storm (VS-69) |
| **Frequency** | Per bank monthly + continuous monitoring |
| **Volume** | ~all locker banks across the network |
| **Owner** | Locker Program Manager / Facilities (VS-138) |
| **Participants** | Facilities, Locker vendor (W4794), Store Ops (VS-07) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Run the PM schedule per bank: lock/door mechanism test, compartment sensors, screen/camera/reader functionality, refrigeration check (W4806) where applicable, structural/weatherproofing (outdoor), and firmware/platform health (W4807); trigger from the asset register | Facilities / Locker Technician | Locker Program Manager / Facilities Lead | Monthly |
| 2 | Monitor hardware health continuously via the platform (W4807): lock-failure rate, sensor faults, connectivity, and reader/camera issues; auto-flag degradation before failure; coordinate with the vendor SLA (W4794) | IT / Facilities / Locker Program | Locker Program Manager | Continuous |
| 3 | Clean and maintain the bank: compartment interiors, screens, cameras, signage/wayfinding (VS-14), and the surrounding area; post-typhoon inspection (VS-69) for outdoor lockers; keep the bank safe/presentable (CX VS-13) | Facilities / Store Ops | Facilities Lead | Continuous |

### System Touchpoints
- Facilities/PM (VS-138 W240 pattern); platform health (W4807); asset register (VS-35); vendor SLA (W4794); analytics (W4815)

### Pain Points / Risks
- **Lock-mechanism-failure risk**: Failed locks → compartments stuck (W4808) or security gap (VS-23); mitigated by lock testing & PM
- **Degradation risk**: Unnoticed gradual sensor/reader degradation → failed pickups; mitigated by health monitoring + predictive maintenance (VS-133)
- **Storm-damage risk**: Typhoon/water damage to outdoor lockers (VS-69); mitigated by weatherproofing + post-storm inspection

### Automation Opportunity
- Platform-health-driven PM scheduling; predictive-fault from pattern analytics; auto-fault ticketing (W4810)

### Controls
- CTL-724 (ensure controlled execution — Maintenance, Integration, Compliance & Network Analytics (PA-164.3).)
- CTL-724: monthly PM per bank; locks/sensors/readers tested; bank cleaned/maintained; refrigeration checked (W4806)

### Time Estimate
- ~per bank PM 1–2 hrs; ~continuous monitoring absorbed

### Cross-references
- links to VS-138 (facilities PM), VS-35 (asset), VS-69 (typhoon), W4807 (platform health), W4810 (fault response), W4815 (analytics)

## W4810. Reactive Fault Triage, Field Repair & Vendor Dispatch

| Field | Detail |
|---|---|
| **Trigger** | Platform fault alert (W4807); customer-reported fault; failed pickup |
| **Frequency** | Per fault |
| **Volume** | ~40–100 locker faults/month at scale (scales with network size) |
| **Owner** | Locker Program Manager / Facilities (VS-138) / IT (VS-27) |
| **Participants** | Locker technician, Vendor (W4794), Store Ops (VS-07), IT (VS-27), CX (VS-13) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Triage the fault from platform data: classify (lock/sensor/screen/reader/connectivity/refrigeration/security), severity (safety/security-critical vs degraded), and scope (single compartment/bank/site/network); safety/security faults → immediate response (W4811) | Facilities / IT / Locker Program | Locker Program Manager | Per fault |
| 2 | Dispatch repair: in-house technician for simple fixes (lock/sensor/clean/restart) or vendor field service under SLA (W4794); manage spare-parts (VS-31), customer impact (re-route orders W4804, notify affected customers W4805), and the repair SLA | Facilities / Vendor / Procurement / CX | Locker Program Manager | Per fault |
| 3 | Restore, retest, and return to service: verify the fix end-to-end (pickup test), update the asset/fault record (VS-35/W4807), feed root-cause to PM/analytics (W4809/W4815), and escalate recurring manufacturer defects to vendor/warranty (W4794) | Facilities / Locker Program | Locker Program Manager | Per fault |

### System Touchpoints
- Platform fault/asset (W4807); facilities/service (VS-138); parts (VS-31); vendor SLA (W4794); CX (VS-13); analytics (W4815)

### Pain Points / Risks
- **Long-downtime risk**: Slow fault response → failed pickups + poor CX; mitigated by SLA + spare-parts availability
- **Security-fault risk**: A lock/security fault → theft exposure (VS-23/W4811); mitigated by immediate response
- **Recurring-defect risk**: Same fault repeating across banks; mitigated by root-cause → vendor escalation

### Automation Opportunity
- Platform auto-fault-ticket + dispatch; parts-availability check; pickup-test automation; root-cause analytics

### Controls
- CTL-724 (ensure controlled execution — Maintenance, Integration, Compliance & Network Analytics (PA-164.3).)
- CTL-724: faults triaged & dispatched per SLA; security faults responded immediately; fixes retested; root-cause fed to PM

### Time Estimate
- ~per fault 1 hr–1 day depending on severity/parts

### Cross-references
- links to VS-138 (facilities), VS-31 (parts), VS-27 (IT), W4794 (vendor SLA), W4807 (platform), W4804/W4805 (customer impact), W4811 (security), W4815 (analytics)

| **Owner** | LP Director (VS-23) / Locker Program |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Respond to the security event: tamper/vandalism/theft at a locker (especially outdoor/off-site W4798); preserve camera evidence (VS-23), secure the bank, and assess customer/merchandise impact; coordinate with police for theft/vandalism (VS-159 pattern) | LP / Store Ops / Police | LP Director / Locker Program Manager | Per event |

### Controls

| 2 | Handle DSAR per RA 10173 (VS-91.2 W271): access, correction, erasure (where legally permissible), objection; manage consent for camera/recording ( signage notice), 3P-recipient data sharing (W4799 DPA), and the do-not-track/opt-out; coordinate with the DPO | Privacy / Locker Program / IT | DPO | Per DSAR |

| **Participants** | PMO (VS-112), Facilities (VS-138), IT (VS-27), OCM (VS-134), CX (VS-13) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
