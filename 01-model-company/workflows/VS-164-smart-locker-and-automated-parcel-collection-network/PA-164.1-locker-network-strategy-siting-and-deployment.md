## W4793. Smart-Locker Network Strategy, Business Model & Roadmap

| Field | Detail |
|---|---|
| **Trigger** | Program launch; annual strategy review; omnichannel growth (VS-10); new-store (VS-37)/remodel (VS-109) |
| **Frequency** | Annual + on launch |
| **Volume** | 1 group strategy; ~1–3 locker banks/site (in-store + parking + off-site) → group-wide locker network |
| **Owner** | GM, Digital Commerce Inc. / Smart-Locker Network Program Manager |
| **Participants** | Ecommerce (VS-10), Store Ops (VS-07), Real Estate (VS-97), Finance (VS-17.4), IT (VS-27) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Set the network strategy & business model: locker types (in-store BOPIS lockers, parking-lot drive-up lockers, off-site transit/condo/mall lockers), own-operate vs locker-vendor partnership (W4794), the use-case mix (BOPIS collection W4801, returns drop-off W4803, 3P parcel pickup W4805), pricing (free BOPIS vs fee-based 3P/oversize/overstay), and the off-site host-revenue model | Locker Program Manager / Ecommerce / Finance | GM, Digital Commerce Inc. / COO | Annual |
| 2 | Build the strategic case: BOPIS convenience/conversion uplift (out-of-hours + no-queue), returns-friction reduction (VS-32), incremental footfall/basket from locker pickups, 3P-parcel-pickup revenue, capex/opex, and the customer-experience/competitive differentiation; define KPIs (lockers, pickup-success, returns via locker, 3P parcels, footfall-to-basket) | Locker Program Manager / Finance / Analytics | GM, Digital Commerce Inc. / CFO | Annual |
| 3 | Approve the multi-year roadmap & capex envelope (W4800); integrate into omnichannel strategy (VS-10), capex (VS-40/VS-112), and the store-remodel/new-store programs (VS-109/VS-37); sequence by BOPIS density and site economics | Locker Program Manager / PMO / Strategy | COO / CFO | Annual |

### System Touchpoints
- FP&A/strategy (VS-33/VS-17.4); capex (VS-40/VS-112); ecommerce (VS-10); real estate (VS-97); analytics (VS-28)

### Pain Points / Risks
- **Premature-build risk**: Over-building lockers ahead of BOPIS demand → stranded capex; mitigated by demand modeling and phasing
- **Use-case-mix risk**: Wrong locker mix (too few oversize for bulky BOPIS; too many small for apparel-style) → poor fit; mitigated by basket modeling
- **Strategic-invisibility risk**: Program cut if footfall/basket uplift not measured; mitigated by the KPI set

### Automation Opportunity
- BOPIS-density/demand forecasting; own-vs-partner decision support; footfall-to-basket attribution (VS-28)

### Controls
- CTL-722 (ensure controlled execution — Locker Network Strategy, Siting & Deployment (PA-164.1).)
- CTL-722: annual business case reviewed by CFO/COO; phased rollout gated on pickup/returns/3P KPIs; capex via VS-40 gate

### Time Estimate
- ~3–5 weeks annual strategy; ~phase-gate reviews quarterly

### Cross-references
- links to VS-10 (ecommerce/BOPIS), VS-33 (strategy), VS-40/VS-112 (capex/PMO), VS-97 (real estate), VS-109/VS-37 (remodel/new-store); sets inputs for W4794–W4800

### Steps

| # | Activity | Role (R) | Role (A) | Duration |

| 2 | Select placement & size: in-store (near entrance/customer-service for BOPIS+returns), parking-lot drive-up (out-of-hours pickup), and off-site (transit/condo/mall host W4798); size the bank to peak BOPIS + 3P + buffer; sequence into the capex plan (W4800) | Locker Program Manager / Real Estate / Store Ops | GM, Digital Commerce Inc. | Per phase |

### Controls

### Time Estimate
