## W4777. EVSE Hardware Specification, Standards & Procurement

| Field | Detail |
|---|---|
| **Trigger** | Own-operate deployment (W4776); EVSE refresh; CPO hardware selection (W4770) |
| **Frequency** | Per procurement batch |
| **Volume** | ~2–6 charge points/site; ~group-wide ports in phases |
| **Owner** | EV Program Manager / Procurement (VS-03/VS-34) |
| **Participants** | EVSE vendors, Energy (VS-108), Facilities (VS-138), TPRM (VS-161) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Specify the EVSE hardware: charging level (AC L2 Type-2 up to 22 kW for dwell/destination; DC fast-charge CCS2 50–150+ kW for high-traffic/throughway sites), connector standards for the PH market, smart/networked (OCPP-compliant), metering accuracy (DTI weights & measures / VS-115), PWD-accessible design, durability for tropical/outdoor conditions, and cybersecurity hardening | EV Program / Energy / Facilities | EV Program Manager | Per batch |
| 2 | Procure via RFP/panel: evaluate vendors on hardware, OCPP/OCPI compliance, warranty/parts (VS-31), TPRM cyber/financial DD (VS-161), and total cost of ownership; negotiate warranty, SLA, spare-parts lead time, and software-update commitment | Procurement / EV Program / TPRM | COO | Per batch |
| 3 | Receive, asset-register (VS-35), and stage EVSE for installation (W4778); capture firmware baseline and certificates (electrical safety, DOE-EVCS provider accreditation where applicable); manage vendor performance ongoing (W4792) | Procurement / Facilities / Asset Mgmt | EV Program Manager | Per batch |

### System Touchpoints
- Procurement/PO (VS-03/VS-34); asset register (VS-35); TPRM (VS-161); parts/quality (VS-31); facilities (VS-138)

### Pain Points / Risks
- **Standards-mismatch risk**: EVSE with the wrong connector/standard → stranded customers; mitigated by PH-market connector spec
- **Cyber risk**: Networked EVSE as an IoT attack surface (VS-161/VS-27.3); mitigated by cyber DD and OCPP-security config
- **Metering-accuracy risk**: Inaccurate metering → billing disputes/revenue leakage; mitigated by VS-115 calibration/verification

### Automation Opportunity
- Vendor-configurator; TCO auto-comparison; asset-register auto-creation on receipt (VS-35)

### Controls
- CTL-720 (ensure controlled execution — Station Deployment, Energy Integration & Roaming/Payment (PA-163.2).)
- CTL-720: OCPP/OCPI + cyber + metering-accuracy in spec; TPRM DD; warranty/parts SLA; assets registered (VS-35)

### Time Estimate
- ~per batch 6–10 weeks (spec → procure → receive)

### Cross-references
- links to VS-03/VS-34 (procurement), VS-35 (asset), VS-161 (TPRM), VS-31 (parts), VS-115 (metering calibration), W4770 (vendor), W4778 (install)

## W4778. Site Civil & Electrical Construction, EVSE Installation & Commissioning

| Field | Detail |
|---|---|
| **Trigger** | Site selected (W4771) & EVSE procured (W4777); capex approved (W4776) |
| **Frequency** | Per site |
| **Volume** | ~10–25 prioritized sites per phase (per the W4769 roadmap: ~400–1,200 ports across ~205 sites) |
| **Owner** | EV Program Manager / Facilities (VS-138) / Construction (VS-20) |
| **Participants** | Electrical contractor, Facilities (VS-138), Energy (VS-108), Real Estate (VS-97) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Execute site civil & electrical construction: trenching/conduit, EVSE pad/foundations, electrical panel/transformer upgrades (coordinate utility W4779), PWD-accessible bay layout (RA 7277/BP 344), signage/wayfinding (VS-14), lighting, and protection from vehicles/weather; manage via the construction playbook (VS-20/VS-109) | Facilities / Construction / Contractor | EV Program Manager / Facilities Lead | Per site |
| 2 | Install and mechanically/electrically commission the EVSE: mount, connect to the electrical infrastructure (W4779) and to solar/storage where applicable (W4780), energize per Philippine Electrical Code safety standards, configure OCPP to the CSMS (W4781), and run the commissioning test suite (charge handshake, metering, emergency-stop, GFCI, comms) | Facilities / EVSE vendor / Energy | EV Program Manager | Per site |
| 3 | Obtain electrical inspection & certification (Philippine Electrical Code), the LGU installation permit sign-off (W4774), and as-built documentation; record assets (VS-35) and hand to operations with the site-acceptance test (W4784) | Facilities / Compliance / Asset Mgmt | EV Program Manager | Per site |

### System Touchpoints
- Construction/facilities (VS-20/VS-138/VS-109); compliance/permits (VS-22/VS-76); asset register (VS-35); signage (VS-14)

### Pain Points / Risks
- **Safety-defect risk**: A mis-wired high-voltage EVSE → fire/shock/injury; mitigated by electrical inspection and the commissioning test suite
- **Accessibility-non-compliance risk**: Bays not PWD-accessible → RA 7277/BP 344 violation; mitigated by accessible-bay spec
- **Rework risk**: Construction without utility/permit coordination → rework; mitigated by the playbook and dependency management (VS-112)

### Automation Opportunity
- System auto-run of "run the commissioning test suite (charge handshake, metering, emergency-stop, GFCI, comms)" (replaces manual Step 2).
- System auto-capture of "as-built documentation; record assets (VS-35)" (replaces manual Step 3).

### Controls
- CTL-720 (ensure controlled execution — Station Deployment, Energy Integration & Roaming/Payment (PA-163.2).)
- CTL-720: electrical (PEC) inspection passed; PWD-accessible bays; LGU permit signed; OCPP commissioning test passed; as-built recorded

### Time Estimate
- ~per site 2–6 weeks construction + commissioning (varies by scope)

### Cross-references
- links to VS-20/VS-138/VS-109 (construction/facilities/remodel), VS-22/VS-76 (permits), VS-35 (asset), VS-14 (signage), W4774 (permits), W4779/W4780/W4781 (energy/comms), W4784 (acceptance)

## W4780. Solar/Storage Integration & Behind-the-Meter Energy Coordination

| Field | Detail |
|---|---|
| **Trigger** | Site with own solar/storage (VS-108); peak-shaving strategy (W4775) |
| **Frequency** | Per site + continuous optimization |
| **Volume** | ~40–80 sites co-located with BuildRight solar/storage (the rooftop-solar subset of ~205 sites per VS-108) |
| **Owner** | EV Program Manager / Energy (VS-108) |
| **Participants** | Renewable ops (VS-108), Facilities (VS-138), Finance (VS-17) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Integrate the charging load behind-the-meter with BuildRight's own solar PV + battery storage (VS-108): direct solar-to-EV charging (greenest, lowest cost), storage peak-shaving to avoid demand-charges (W4775), and load-balancing across the store + EVSE + storage via the energy management system (EMS) | Renewable Ops / Energy / Facilities | EV Program Manager | Per site |
| 2 | Coordinate energy dispatch: prioritize solar to EVSE when generation is high, discharge storage during peak to shave demand, charge storage off-peak, and manage the trade-off between selling/exporting (net-metering VS-108) vs self-consuming for EV revenue; optimize for cost + decarbonization | Renewable Ops / Energy / Finance | EV Program Manager | Continuous |
| 3 | Account for the green-energy attribute: attribute renewable kWh to EV charging for ESG/decarbonization reporting (VS-25 Scope 2/3) and "100% renewable charging" marketing (VS-14); verify via the REC/metering (VS-108); feed to analytics (W4792) | Energy / ESG / Marketing | EV Program Manager / ESG Lead | Continuous |

### System Touchpoints
- Solar/storage/EMS (VS-108); energy/RA 11285 (VS-120); ESG/GHG (VS-25); finance/cost-allocation (VS-17/VS-72); analytics (W4792)

### Pain Points / Risks
- **Dispatch-suboptimization risk**: Wrong solar→EV vs export decision → lost revenue/carbon; mitigated by the EMS optimization logic
- **Capacity-mismatch risk**: Storage undersized for peak-shaving → demand-charges still trigger; mitigated by load-modeling
- **Green-attribution risk**: Double-counting renewable kWh in ESG (VS-25); mitigated by rigorous REC/metering attribution

### Automation Opportunity
- EMS dispatch optimization (solar→EV vs export vs storage); demand-charge-prediction; green-attribution auto-feed to ESG (VS-25)

### Controls
- CTL-720 (ensure controlled execution — Station Deployment, Energy Integration & Roaming/Payment (PA-163.2).)
- CTL-720: EMS balances store + EVSE + storage; demand-charge managed; renewable kWh attributed once (ESG VS-25)

### Time Estimate
- ~per site integration 2–4 weeks; ~continuous dispatch optimization absorbed

### Cross-references
- links to VS-108 (solar/storage/EMS), VS-120 (energy), VS-25 (ESG/GHG), VS-17/VS-72 (cost-allocation), W4775 (demand-charge), W4792 (analytics)

| 3 | Settle the session: compute the charge (kWh tariff + time + idle-fee − loyalty discount), capture payment (VS-80), issue the BIR-compliant e-invoice/receipt (VS-79 W473), post revenue (VS-17/VS-157), accrue loyalty points (VS-13), and reconcile (W4792) | Payment Ops / Finance / Loyalty | EV Program Manager / Finance | Per session |

## W4784. Go-Live Readiness, Site Acceptance & Hypercare Handover

| Field | Detail |
|---|---|
| **Trigger** | Commissioning complete (W4778/W4781); site about to go live |
| **Frequency** | Per site |
| **Volume** | ~each site at launch |
| **Owner** | EV Program Manager / PMO (VS-112) / Facilities (VS-138) |
| **Participants** | Facilities, IT (VS-27), OCM (VS-134), Store Ops (VS-07), CPO |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Run the go-live readiness & site-acceptance test (SAT): end-to-end test (access → charge → bill → notify → idle-fee), safety checks (emergency-stop, GFCI, signage), accessibility (PWD bays), tariff display (Consumer Act W469), OCPP/OCPI/CSMS health, and store-team readiness; obtain sign-off before public launch | EV Program / Facilities / IT / OCM | EV Program Manager | Per site |
| 2 | Train the store team (VS-134 OCM): basic customer assistance ("how to start a charge"), escalation path for faults (W4789), safety/emergency response, and the basket-offer script (W4773); brief on PWD assistance and the dwell-offer | OCM / Store Ops / EV Program | Store Manager | Per site |
| 3 | Enter hypercare: intensified monitoring (uptime, faults, session success) for the first weeks, rapid-issue resolution with the CPO/vendor, and the transition to steady-state operations (W4789) once stable; capture lessons for the next site (VS-133) | EV Program / IT / CPO | EV Program Manager | Per site |

### System Touchpoints
- PMO/go-live (VS-112); OCM/training (VS-134); IT/CSMS (VS-27/W4781); store ops (VS-07); facilities (VS-138)

### Pain Points / Risks
- **Premature-go-live risk**: Launching with unresolved faults → poor first impression; mitigated by the SAT gate
- **Store-team-unprepared risk**: Staff can't assist/escalate → customer frustration; mitigated by OCM training (VS-134)
- **Hypercare-exit-too-early risk**: steady-state declared before session-success and fault rates stabilize, returning faults to an untrained store team; mitigated by the intensified first-weeks monitoring with the VS-134 training handover (Steps 2–3)

### Automation Opportunity
- SAT checklist automation; CSMS health dashboard; fault-rate-gated hypercare-exit; OCM training module

### Controls
- CTL-720 (ensure controlled execution — Station Deployment, Energy Integration & Roaming/Payment (PA-163.2).)
- CTL-720: SAT passed before public launch; store team trained (VS-134); hypercare exited only on stability criteria

### Time Estimate
- ~per site SAT + hypercare 2–4 weeks

### Cross-references
- links to VS-112 (PMO/go-live), VS-134 (OCM/training), VS-07 (store ops), VS-27/W4781 (CSMS), VS-138 (facilities), VS-133 (lessons), W4789 (steady-state ops)
