## W4449. SCO/Scan-&-Go Loss, Sweethearting & Swap-Fraud Detection

| Field | Detail |
|---|---|
| **Trigger** | SCO operation; loss analytics; exception feed |
| **Frequency** | Continuous (analytics) + per case |
| **Volume** | SCO loss-rate benchmark 2–5× staffed-POS shrink |
| **Owner** | Loss Prevention (VS-23) / Frontend (VS-08) / BI (VS-28) |
| **Participants** | LP (VS-23), Frontend (VS-08), BI (VS-28), Security (VS-27.3), HR (VS-103), Store Ops (VS-07) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | LP/BI run SCO/scan-&-go loss analytics — scan-avoidance (item not scanned), weight-mismatch rate, barcode-swap (cheap-on-expensive), sweethearting (attendant override pattern), and basket-anomaly detection | LP / BI | LP Lead | Continuous |
| 2 | LP triage high-risk cases, pull CCTV/exception evidence (W4450), distinguish customer-fraud from internal-collusion (attendant), and open case (W4450/VS-125) | LP / Security | LP Lead | Per case |
| 3 | LP/Frontend tune the detection rules (W4437), train attendants on collusion-prevention, and handle internal-fraud per HR/legal (VS-103/VS-100) | LP / Frontend / HR | LP Lead / CHRO | Continuous |

### System Touchpoints
- LP analytics/exception (VS-23/W4450); CCTV (VS-23.2); BI (VS-28); fraud case (VS-125); HR (VS-103); security (VS-27.3)

### Pain Points / Risks
- **Undetected-scan-avoidance risk**: SCO loss silently erodes wage savings; mitigated by analytics + weight-security (W4437)
- **Internal-collusion risk**: attendant enables scan-avoidance for accomplice; mitigated by override-pattern analytics & SoD

### Automation Opportunity
- Loss-pattern ML detection; weight-mismatch/swap/sweethearting rules; CCTV/exception auto-correlation; case workflow

### Controls
- CTL-92 (ensure self-checkout loss & compliance control.)
- CTL-679: loss analytics run continuously; cases investigated with evidence; collusion-prevention trained; rules tuned; internal-fraud handled (VS-125)

### Time Estimate
- Continuous analytics; per-case investigation hours

### Cross-references
- links to VS-23 (LP), VS-125 (fraud), VS-23.2 (CCTV), VS-103 (HR), W4437 (loss design), W4450 (exception), W4455 (analytics)
