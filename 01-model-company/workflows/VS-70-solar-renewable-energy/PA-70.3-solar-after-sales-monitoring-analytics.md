## W2542. Solar System Remote Monitoring & Performance Alerting

| Field | Detail |
|---|---|
| **Trigger** | IoT monitoring detects anomaly or scheduled daily performance check |
| **Frequency** | Continuous monitoring; daily summary |
| **Volume** | ~500–1,000 monitored systems (growing at ~600/year) |
| **Owner** | Solar Technical Support |
| **Participants** | Solar Tech Support, Installation Partner, Customer |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | IoT gateway collects real-time data from inverter: power output (kW), daily generation (kWh), grid import/export, inverter temperature, error codes; transmits to ERP via API; system compares actual vs. expected generation based on weather data (irradiance) and system specifications | System / Solar Tech Support | Category Manager | Continuous |
| 2 | System generates alerts: Underperformance (actual <80% of expected for 3 consecutive days), Inverter Error (fault code triggers diagnostic), Communication Loss (no data for 24 hours); Solar Tech Support reviews alerts daily and triages priority | System / Solar Tech Support | Category Manager | 30–60 min/day |
| 3 | For confirmed issues: Tech Support contacts customer, diagnoses remotely (inverter reset, connection check); dispatches installation partner for on-site repair if needed; logs service ticket in ERP; tracks resolution within SLA (non-critical: 5 days, critical: 2 days) | Solar Tech Support / Installer | Category Manager | 30 min – 2 hours per issue |

### System Touchpoints
- IoT data ingestion API from inverter manufacturers
- Performance analytics with weather-correlation model
- Service ticket management with SLA tracking

### Pain Points / Risks
- **IoT reliability**: Internet connectivity at customer sites may be intermittent; data gaps affect monitoring
- **Alert fatigue**: Minor weather-related underperformance generates excessive alerts


### Automation Opportunity
- System auto-import of "import/export, inverter temperature, error codes" (replaces manual Step 1).
- System auto-review of "reviews alerts daily and triages priority" (replaces manual Step 2).
- System auto-log of "logs service ticket in ERP" (replaces manual Step 3).

### Controls
- CTL-441 (ensure controlled execution — Solar After-Sales Monitoring & Analytics (PA-70.3).)
- operational: Solar Technical Support review and approval gate

### Time Estimate
- 30–120 min per occurrence

## W2543. Solar Panel Performance Degradation Tracking

| Field | Detail |
|---|---|
| **Trigger** | Annual performance review cycle or warranty claim |
| **Frequency** | Annual per installed system |
| **Volume** | ~500–1,000 annual reviews (growing) |
| **Owner** | Solar Technical Support |
| **Participants** | Solar Tech Support, Category Manager, Vendor |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System calculates annual degradation rate per installation: compares Year N actual generation vs. Year 1 baseline, normalized for weather (irradiance data); flags installations exceeding panel warranty degradation curve (typically <0.55%/year for Tier 1 panels) | System / Solar Tech Support | Category Manager | 1–2 days/year batch |
| 2 | Tech Support reviews flagged installations: determines if degradation is panel-related (manufacturing defect warrantable) vs. environmental (shading from new construction, soiling from nearby construction dust, vegetation growth) | Solar Tech Support | Category Manager | 30–60 min per case |
| 3 | For warrantable degradation: initiates warranty claim with panel vendor (W2544); provides monitoring data as evidence; coordinates panel testing and replacement. For environmental issues: advises customer on remediation (tree trimming, panel cleaning service) | Solar Tech Support / Vendor | Category Manager | 1–4 weeks per case |

### System Touchpoints
- Performance degradation analytics with weather normalization
- Warranty claim initiation with monitoring evidence attachment
- Customer communication module

### Pain Points / Risks
- **Data insufficiency**: Newer installations lack sufficient baseline data for degradation analysis
- **Vendor disputes**: Panel manufacturers may dispute warranty claims citing environmental factors


### Automation Opportunity
- System auto-calculate of "calculates annual degradation rate per installation" (replaces manual Step 1).
- System auto-review of "reviews flagged installations" (replaces manual Step 2).
- System auto-monitor of "monitoring data as evidence" (replaces manual Step 3).

### Controls
- CTL-441 (ensure controlled execution — Solar After-Sales Monitoring & Analytics (PA-70.3).)
- operational: Solar Technical Support review and approval gate

### Time Estimate
- 30–120 min per occurrence

## W2544. Solar Warranty Claim & Vendor Recovery Processing

| Field | Detail |
|---|---|
| **Trigger** | Customer reports solar product defect or monitoring detects performance issue |
| **Frequency** | ~10–20 warranty claims/month |
| **Volume** | ~10–20/month |
| **Owner** | Solar Sales Coordinator |
| **Participants** | Solar Sales Coord, Vendor, Installation Partner, Finance, Customer |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Coordinator receives warranty claim: customer-submitted via portal or monitoring-triggered; validates warranty status (within coverage period, registered serial number); categorizes: panel defect, inverter failure, battery issue, installation workmanship | Solar Sales Coordinator | Category Manager | 30 min |
| 2 | Coordinator coordinates inspection: dispatches installation partner to diagnose on-site; collects photographic evidence and test data; submits claim to vendor with documentation package per vendor warranty process (varies by manufacturer) | Solar Sales Coordinator / Installer | Category Manager | 3–5 days |
| 3 | Upon vendor approval: Coordinator coordinates replacement delivery and installation; Finance processes vendor credit/replacement PO; system updates warranty record and inventory; if vendor rejects, escalates to Category Manager for resolution or customer accommodation | Solar Sales Coord / Finance / Vendor | Category Manager / Finance | 1–4 weeks |

### System Touchpoints
- Warranty claim management with multi-vendor routing
- Service dispatch for warranty inspection
- Vendor credit/replacement PO processing

### Pain Points / Risks
- **Long vendor processing**: Import vendor warranty claims take 4–8 weeks for resolution
- **Customer downtime**: System non-operational during warranty resolution


### Automation Opportunity
- System auto-validate of "Coordinator receives warranty claim" (replaces manual Step 1).
- System auto-document of "documentation package per vendor warranty process" (replaces manual Step 2).
- System auto-record of "record and inventory" (replaces manual Step 3).

### Controls
- CTL-441 (ensure controlled execution — Solar After-Sales Monitoring & Analytics (PA-70.3).)
- operational: non-operational during warranty resolution

### Time Estimate
- 30–120 min per occurrence

## W2545. Solar Installation Partner Performance Scoring

| Field | Detail |
|---|---|
| **Trigger** | Monthly review cycle |
| **Frequency** | Monthly |
| **Volume** | ~10–20 installation partners |
| **Owner** | Category Manager — Electrical |
| **Participants** | Category Mgr, Solar Sales Coordinator, VP Merchandising |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System generates partner scorecard: installation quality (inspection pass rate target ≥95%), schedule adherence (on-time installation target ≥90%), customer satisfaction (NPS from post-install survey), warranty claim rate (<5% within first year), safety incidents (zero tolerance) | System / Solar Sales Coordinator | Category Manager | 1–2 hours |
| 2 | Category Manager reviews scorecards; conducts monthly performance call with each partner; for underperformers: issues corrective action plan with 30-day improvement window; for top performers: increases lead allocation and explores volume commitments | Category Manager | VP Merchandising | 2–3 hours |
| 3 | Quarterly: Category Manager evaluates partner portfolio; onboards new partners in underserved regions (especially Visayas/Mindanao); terminates chronically underperforming partners per contract terms; maintains minimum 2 partners per region for competition | Category Manager / Procurement | VP Merchandising | 1 day/quarter |

### System Touchpoints
- Partner performance dashboard with automated scoring
- Inspection pass rate tracking from Oracle Quality (fit-gap C12)
- Customer NPS integration from CRM

### Pain Points / Risks
- **Partner scarcity**: Limited ERC-licensed solar installers in some provincial markets
- **Quality inconsistency**: Partners using subcontractors without adequate oversight


### Automation Opportunity
- System auto-inspect of "inspection pass rate target ≥95%" (replaces manual Step 1).
- System auto-review of "Category Manager reviews scorecards" (replaces manual Step 2).

### Controls
- CTL-441 (ensure controlled execution — Solar After-Sales Monitoring & Analytics (PA-70.3).)
- operational: Category Manager — Electrical review and approval gate

### Time Estimate
- 30–120 min per occurrence

| **Frequency** | ~40–60 surveys/month |
| **Volume** | ~40–60/month |
| **Owner** | Customer Experience Analyst |
| **Participants** | CX Analyst, Category Manager, Solar Sales Coordinator |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System sends automated NPS survey 30 days post-installation: product satisfaction, installation experience, communication quality, value for money, likelihood to recommend (0–10), open comments; survey completion target: >40% response rate | System / CX Analyst | COO | Automated |

- System auto-inspect of "inspection, performance optimization, partial refund if warranted" (replaces manual Step 3).

## W2548. Solar Product Return & Exchange Processing

| Field | Detail |
|---|---|
| **Trigger** | Customer requests return of solar product (pre-installation) or defective unit replacement |
| **Frequency** | ~10–20 returns/month |
| **Volume** | ~10–20/month |
| **Owner** | Store Customer Service Rep |
| **Participants** | Customer Service Rep, Department Supervisor, Category Manager, Vendor |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Customer Service Rep processes return request: verifies purchase within 30-day return window (standard) or warranty period (defective); for panels/inverters — inspects for physical damage; for special-order items — confirms return authorization per vendor policy | Customer Service Rep | Department Supervisor | 20–30 min |
| 2 | Supervisor approves return; system processes refund (cash/card reversal) or exchange; for defective items: creates vendor return authorization request; items placed in defective quarantine area; customer receives replacement from stock or special order | Department Supervisor | Store Manager | 15–30 min |
| 3 | Category Manager reviews return trend monthly: high return rate SKUs flagged for quality review with vendor; defective analysis by vendor, product type, and batch/lot; adjusts inventory buffers for high-return SKUs | Category Manager | VP Merchandising | 1–2 hours/month |

### System Touchpoints
- Return processing with vendor RMA integration
- Inventory quarantine management
- Return analytics dashboard

### Pain Points / Risks
- **High-value returns**: Solar panel returns are PHP 8K–25K per panel; strict inspection required
- **Vendor disputes**: Vendor may reject return claiming customer damage


### Automation Opportunity
- System auto-inspect of "inspects for physical damage" (replaces manual Step 1).
- System auto-create of "creates vendor return authorization request" (replaces manual Step 2).
- System auto-review of "reviews return trend monthly" (replaces manual Step 3).

### Controls
- CTL-441 (ensure controlled execution — Solar After-Sales Monitoring & Analytics (PA-70.3).)
- operational: Store Customer Service Rep review and approval gate

### Time Estimate
- 30–120 min per occurrence

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
