## Overview

Operational Excellence (OpEx), Process Mining & Continuous Improvement workflows for BuildRight
Depot Corp. — owning the enterprise discipline of **systematically discovering, analyzing, and
improving** the cross-functional processes that run a PHP 62.3B, 200-store, 4-DC, ~6,932-employee,
~2.8M-monthly-transaction operation. BuildRight runs ~5,433 documented workflows; without a
dedicated OpEx/CI program, inefficiency compounds — cycle-time drag, rework, manual handoffs,
process variants, and unrealized automation collectively erode the 12–14% EBITDA target and the
6–8x inventory-turn target.

Today this discipline is **entirely unowned as a program**: VS-30 (Innovation & Digital) scouts
*emerging technology and runs PoCs/RPA*; VS-21 (Internal Audit) *assures* controls and flags
findings but does not own remediation/improvement; VS-112 (PMO) delivers *projects*; VS-27
(IT Operations) runs the *service desk* — but no value stream owns the **continuous-improvement
operating system**: process architecture & ownership, Lean/Six Sigma methodology, an improvement
opportunity pipeline, process mining/task mining from ERP event logs, bottleneck & root-cause
analysis, standard-work/SOP authoring, pilot execution, benefit-case modeling & realization,
productivity/cost-out programs, and a culture of kaizen. The defining terms 'operational
excellence', 'process mining', 'continuous improvement', 'lean', 'six sigma', and 'kaizen'
appeared in **zero** PA files as dedicated workflow headers (the only matches were literal
"cleaning/cleanup" workflows); the discipline is genuinely unowned.

This is distinct from **VS-30 (Innovation & Digital)** which scouts emerging tech and runs PoCs
(this value stream owns the *process-improvement methodology* that identifies which processes to
automate and proves the benefit). It is distinct from **VS-21 (Internal Audit & Risk)** which
*assures* controls and reports findings (this value stream owns *remediation and improvement* —
audit is a key input/feed). It is distinct from **VS-112 (Corporate PMO)** which governs the
*project portfolio* (this value stream owns the *process* layer and the CI methodology that
projects apply). It is distinct from **VS-27 (IT Operations)** which runs the *service desk*
(this value stream owns business-process improvement across all functions, not IT services).
Operational excellence is the *systematic-improvement* discipline — distinct from innovation,
audit, project management, and IT service management.

BuildRight's exposure is structural: a high-volume, multi-entity, geographically distributed
operation with long import lead times, island logistics, and a lean staffing model has thin
tolerance for process inefficiency; every percentage point of process waste, cycle-time, or
rework translates directly into margin and service-level erosion that no existing value stream
owns end-to-end.
