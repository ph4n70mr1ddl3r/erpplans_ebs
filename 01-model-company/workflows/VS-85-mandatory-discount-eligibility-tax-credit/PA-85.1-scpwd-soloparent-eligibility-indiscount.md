## W2897. SC/PWD/Solo Parent ID Validation & Eligibility Verification at POS

| Field | Detail |
|---|---|
| **Trigger** | Customer presents discount ID at checkout |
| **Frequency** | ~140,000–225,000 transactions/month (5–8% of POS) |
| **Volume** | 600 POS terminals; 200 stores |
| **Owner** | Store Manager |
| **Participants** | Cashier, Customer, Store Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier validates ID: OSCA Senior ID / PhilSys for seniors; PWD ID from NCDA-accredited LGU; Solo Parent ID from LGU; checks photo, validity, and ownership | Cashier | Store Manager | Per transaction |
| 2 | Cashier captures ID number and customer name in POS; ERP applies statutory discount and records transaction in mandatory-discount register | Cashier | Store Manager | Per transaction |
| 3 | Store Manager resolves disputes (expired ID, eligibility question) per protocol; denies discount with courteous explanation where invalid | Store Manager | Store Manager | Per dispute |

### System Touchpoints
- POS mandatory-discount module; ID validation; discount register

### Pain Points / Risks
- **Compliance risk**: Granting discount without valid ID forfeits tax credit; mitigated by mandatory ID capture in POS


### Automation Opportunity
- System auto-validate of "checks photo, validity, and ownership" (replaces manual Step 1).
- System auto-record of "records transaction in mandatory-discount register" (replaces manual Step 2).
- System auto-count of "discount with courteous explanation where invalid" (replaces manual Step 3).

### Controls
- CTL-236 (ensure mandatory-discount & VAT-exemption compliance.)
- operational: mandatory ID capture in POS; operational: ID capture in POS

### Time Estimate
- 1–2 min per transaction

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Pricing configures discount rules: 20% SC/PWD (5% for groceries per RA 9994 for selected prime commodities; 32% for medicines under RA 10754 = 20% discount + 12% VAT-exempt); 10% Solo Parent on selected goods/baby items | Pricing | VP Merchandising | Per rule |

- System auto-log of "IT implements stack-prevention logic" (replaces manual Step 2).
- System continuous audit of "audits POS application vs." (replaces manual Step 3).

### Controls
