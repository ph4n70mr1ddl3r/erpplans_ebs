## W4913. Uniform, Workwear & PPE Program Strategy & Operating Model

| Field | Detail |
|---|---|
| **Trigger** | Program launch; annual HR/brand review; format evolution (VS-109); cost-pressure |
| **Frequency** | Annual + on launch |
| **Volume** | 1 group program applied to ~6,932 employees + ~10–20% contingent + vendor personnel across 205 sites |
| **Owner** | CHRO / Uniform & Workwear Program Manager (HR Shared Services VS-103) |
| **Participants** | HR (VS-19/VS-103), HSE (VS-24), Brand/Marketing (VS-14), Procurement (VS-03/VS-34), Finance (VS-17.4), Store Ops (VS-07) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Set the uniform/workwear/PPE program strategy & operating model: the brand-appearance standard aligned to "Your Home Building Partner", the own-issue vs allowance decision, the in-house vs vendor-laundering model, the role-based coverage (store floor, lumber yard, paint/chemical, DC, drivers, HQ, contingent), and the program owner (HR Shared Services VS-103) | Program Manager / HR / Brand / HSE | CHRO / COO | Annual |
| 2 | Build the strategic case & budget: CX/brand-consistency across 200 stores, DOLE-OSH PPE compliance, employee-experience/retention impact (links VS-141/VS-144 EX), the opex/allowance/laundering/PPE envelope (~PHP 20–55M/yr), and KPIs (compliance %, cost/employee, satisfaction, PPE-failure rate); sequence into the HR & capex plans | Program Manager / Finance / Analytics | CHRO / CFO | Annual |
| 3 | Approve the program charter, policy (W4916), and governance (W4920); integrate into HR operations (VS-19/VS-103), HSE (VS-24), procurement (VS-03/VS-34), and the store-remodel/new-store programs (VS-109/VS-37) | Program Manager / Strategy / HR | CHRO / COO | Annual |

### System Touchpoints
- HR/HRSS (VS-19/VS-103); HSE (VS-24); brand (VS-14); procurement (VS-03/VS-34); FP&A (VS-17.4/VS-33); analytics (VS-28)

### Pain Points / Risks
- **Strategic-invisibility risk**: Program seen as a cost not a CX/brand/compliance lever; mitigated by the balanced KPI set (W4929)
- **Coverage-gap risk**: Contingent/vendor personnel excluded → inconsistent appearance & PPE gap; mitigated by the role-based coverage model (W4923)
- **Operating-model risk**: Wrong own-vs-vendor / allowance-vs-issue decision → cost/quality trade-off; mitigated by the strategy analysis

### Automation Opportunity
- Cost/employee modeling; coverage-gap analytics; own-vs-vendor decision support; allowance vs issue modeling

### Controls
- CTL-737 (ensure controlled execution — Uniform & Workwear Program Strategy, Policy & Sourcing (PA-169.1).)
- CTL-737: annual business case reviewed by CHRO/CFO; operating model documented; coverage model defined

### Time Estimate
- ~4–6 weeks annual strategy; ~quarterly phase-gate reviews

### Cross-references
- links to VS-19/VS-103 (HR/HRSS), VS-24 (HSE/PPE), VS-14 (brand), VS-03/VS-34 (procurement), VS-33/VS-17.4 (strategy/FP&A), VS-109/VS-37 (remodel/new-store); sets inputs for W4914–W4920

## W4914. Role-Based Uniform / Workwear Standards & Brand-Guideline Design

| Field | Detail |
|---|---|
| **Trigger** | Strategy set (W4913); brand refresh (VS-14); role/structure change |
| **Frequency** | Per refresh + on role change |
| **Volume** | ~15–20 role-types (store floor, supervisor, cashier, lumber-yard, paint, receiving, DC) |
| **Owner** | Uniform & Workwear Program Manager / Brand / HR |
| **Participants** | Brand/Marketing (VS-14), HR (VS-19), HSE (VS-24), Store Ops (VS-07), Supplier (W4917) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Define the role-based uniform/workwear standard per brand guidelines (VS-14): garment types (polo/tee, trousers, jacket/rainwear for yard/outdoor, hi-vis for DC/yard, smock for paint, anti-static where needed), fabric/durability (heavy-use, wash-frequency, tropical-climate breathability), color/branding/logo placement, footwear, and name/role identification | Brand / Program Manager / HR / HSE | CHRO / VP Marketing | Per refresh |
| 2 | Map standards to roles & work-zones: store-floor vs lumber-yard (hi-vis/steel-toe) vs paint/chemical (smock + PPE W4915) vs DC (hi-vis/steel-toe) vs delivery driver (branded + hi-vis) vs HQ; define the onboarding kit quantity & replenishment cycle (W4916) | Program Manager / Store Ops / HSE / HR | Program Manager | Per refresh |
| 3 | Publish & train: issue the uniform standard to HR/stores/suppliers (links VS-63), brief managers on enforcement & the appearance policy (grooming, accessories, PPE-compliance), and audit adherence (W4930) | Brand / HR / Store Ops / Training | Program Manager | Continuous |

### System Touchpoints
- Brand/DAM (VS-14/VS-137); HR/HRIS role master (VS-19/VS-29); store comms (VS-63); HSE (VS-24); supplier portal (VS-03.4)

### Pain Points / Risks
- **Brand-inconsistency risk**: Off-brand/non-standard uniforms → CX/brand erosion; mitigated by the published standard + audit
- **Climate-mismatch risk**: Non-breathable fabric in tropical stores → discomfort/health; mitigated by fabric/durability spec
- **Role-coverage risk**: A role/zone missing the right garment/PPE; mitigated by the role-zone mapping

### Automation Opportunity
- Role-to-uniform auto-mapping from HRIS role master; DAM brand-asset sync (VS-137); standard-publish via store-comms (VS-63)

### Controls
- CTL-737 (ensure controlled execution — Uniform & Workwear Program Strategy, Policy & Sourcing (PA-169.1).)
- CTL-737: brand-guideline-aligned standard; role-zone coverage complete; climate-appropriate fabric; adherence-audited

### Time Estimate
- ~initial standard 3–4 weeks; ~refresh 1–2 weeks; ~ongoing training absorbed into VS-19.4

### Cross-references
- links to VS-14 (brand/DAM), VS-19/VS-29 (role master), VS-24 (HSE), VS-63 (store comms), VS-03.4 (supplier portal), W4915 (PPE), W4916 (allowance), W4930 (audit)

## W4915. PPE Standards, Role Hazard Assessment & Issuance Matrix

| Field | Detail |
|---|---|
| **Trigger** | Strategy set (W4913); new role/equipment/process; HSE review (VS-24); incident |
| **Frequency** | Per hazard-assessment cycle + on change |
| **Volume** | ~8–10 PPE categories (hard hat, safety shoes/steel-toe, hi-vis, eye/face, hearing, respiratory) |
| **Owner** | HSE (VS-24) / Uniform & Workwear Program Manager |
| **Participants** | HSE (VS-24), HR (VS-19), Store Ops (VS-07), DC Ops (VS-04), Occupational Health (VS-83), Procurement (VS-03/VS-34) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Conduct role-based hazard assessments (links VS-24): per role/work-zone (lumber-yard forklift, paint/chemical handling, DC manual handling, cutting station, electrical work, working-at-height, driving), identify required PPE per DOLE-OSH standards, manufacturer specs, and the PPE hazard hierarchy | HSE / Operations / Occupational Health | HSE Lead | Per cycle |
| 2 | Build the PPE issuance matrix: role → required-PPE list → standard/spec → issue-quantity → replacement-cycle → fit-test requirement (e.g., respiratory fit-test, harness inspection); align to the uniform standard (W4914) and DOLE compliance (W4930) | HSE / Program Manager | HSE Lead | Per cycle |
| 3 | Govern PPE standards, certification & change: source certified PPE (links VS-117/VS-31 quality), update the matrix on role/equipment/process/incident change, and verify via the issuance & audit cycle (W4922/W4930) | HSE / Procurement / Quality | HSE Lead | Continuous |

### System Touchpoints
- HSE (VS-24); HRIS role master (VS-19/VS-29); quality/cert (VS-31/VS-117); procurement (VS-03/VS-34); occupational health (VS-83); asset/inventory (VS-35)

### Pain Points / Risks
- **OSH-liability risk**: Missing/wrong/worn PPE → injury + DOLE finding/officer liability; mitigated by the hazard assessment + matrix + audit
- **Certification risk**: Non-certified PPE failing to protect (VS-117); mitigated by certified sourcing + quality
- **Coverage-gap risk**: A role/equipment not assessed → unissued PPE; mitigated by the change-triggered reassessment

### Automation Opportunity
- Role-hazard auto-mapping; PPE-matrix from HRIS role + equipment master; fit-test scheduling; change-triggered reassessment

### Controls
- CTL-737 (ensure controlled execution — Uniform & Workwear Program Strategy, Policy & Sourcing (PA-169.1).)
- CTL-737: role-based hazard assessment complete; PPE matrix per DOLE; certified PPE (VS-117); fit-test tracked; audited (W4930)

### Time Estimate
- ~initial assessment 3–5 weeks; ~per-cycle refresh 1–2 weeks; ~change-triggered per change

### Cross-references
- links to VS-24 (HSE), VS-31/VS-117 (quality/cert), VS-19/VS-29 (role master), VS-83 (occupational health), VS-03/VS-34 (procurement), W4914 (uniform), W4922 (issuance/fit-test), W4930 (compliance)

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Design the allowance/replenishment policy: own-issue vs cash-allowance vs hybrid per role, the onboarding kit quantity, the replenishment cycle (e.g., annual set + wear-out replacement), PPE replacement-on-condition, and the rules for damage/loss/theft (chargeable vs company-borne); align to total rewards (VS-102) | Program Manager / Total Rewards / Finance | CHRO / CFO | Annual |
| 2 | Configure the allowance in payroll/HRIS (VS-19.2/VS-29): allowance amount per role, taxable vs non-taxable treatment (BIR/DOLE), replenishment triggers, and the reconciliation between allowance paid and uniforms issued (avoid double-dip); manage the employee self-service request flow (VS-103) | Payroll / HRSS / Finance | Program Manager | Annual |
| 3 | Communicate & govern: publish the policy to employees/managers (links VS-103), enforce the replenishment cycle, track allowance vs actual-issue variance (W4929), and review annually with total rewards & finance | HRSS / Program Manager / Finance | CHRO | Continuous |

### System Touchpoints

### Pain Points / Risks
- **Double-dip risk**: Allowance paid AND uniforms issued → cost leakage; mitigated by the reconciliation
- **Policy-fairness risk**: Inconsistent allowance across roles/entities → grievance (VS-84); mitigated by the role-based policy + governance
- **Replenishment-gap risk**: Worn-out uniforms not replaced within cycle → CX/brand harm; mitigated by the enforced cycle

### Controls
- CTL-737 (ensure controlled execution — Uniform & Workwear Program Strategy, Policy & Sourcing (PA-169.1).)

## W4918. Sizing, Fit & Body-Measurement Program

| Field | Detail |
|---|---|
| **Trigger** | New-hire onboarding (VS-121/VS-19); vendor change (W4917); fit-complaint |
| **Frequency** | Per employee (onboarding) + per vendor fit |
| **Volume** | ~1,200–1,600 new hires/yr × sizing + ongoing fit adjustments |
| **Owner** | Uniform & Workwear Program Manager / HR Shared Services (VS-103) |
| **Participants** | HR (VS-19/VS-121), Supplier (W4917), Store Ops (VS-07), Privacy/DPO (VS-91) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Establish the sizing program: standard size-chart per garment (aligned to the supplier W4917), the measurement method (self-measure kit / in-store fitting / body-scan opt-in), the inclusive size range (including maternity, PWD-adaptive), and the data-privacy handling of body-measurement data (RA 10173 — minimize, consent, limited retention) | Program Manager / HRSS / Privacy / Supplier | Program Manager | Per program |
| 2 | Capture sizing at onboarding (links VS-121): measure/fit each new hire against the chart, capture into HRIS/ESS (VS-29/VS-103) under privacy controls, order the right-size onboarding kit (W4921), and handle fit-issues/exchanges (W4926) | HRSS / Supplier / Store Ops | Program Manager | Per hire |
| 3 | Manage vendor fit & size-range: validate the supplier's sizing against the actual workforce (avoid systemic mis-fit), expand the size range for inclusivity, and use body-measurement data only for fit (privacy-minimized, no other HR use) | Program Manager / Supplier / Privacy | Program Manager | Continuous |

### System Touchpoints
- HRIS/ESS sizing module (VS-29/VS-103); supplier ordering (VS-03.4); privacy/DPO (VS-91); analytics (VS-28)

### Pain Points / Risks
- **Privacy risk**: Body-measurement data misused/over-retained (RA 10173); mitigated by minimization + consent + limited retention
- **Mis-fit risk**: Wrong-size kit → re-issue cost + employee dissatisfaction; mitigated by the validated chart + fitting
- **Inclusivity risk**: Limited size range excluding body types; mitigated by the inclusive range

### Automation Opportunity
- ESS sizing capture; size-chart auto-match; body-scan opt-in (privacy-governed); fit-issue auto-flag

### Controls
- CTL-737 (ensure controlled execution — Uniform & Workwear Program Strategy, Policy & Sourcing (PA-169.1).)
- CTL-737: RA 10173-compliant sizing data (minimize/consent/retain-limited); validated size chart; inclusive range

### Time Estimate
- ~per-hire sizing 10–15 min; ~vendor-fit validation per vendor cycle; ~program setup 2–3 weeks

### Cross-references
- links to VS-29/VS-103 (HRIS/ESS), VS-91 (privacy), VS-121/VS-19 (onboarding), VS-03.4 (supplier), W4917 (vendor), W4921 (issuance), W4926 (exchange)
