## W4929. Uniform / PPE Program Cost, Spend & TCO Analytics

| Field | Detail |
|---|---|
| **Trigger** | Program live (W4913); monthly/quarterly review; FP&A cycle (VS-17.4) |
| **Frequency** | Continuous analytics + monthly/quarterly review |
| **Volume** | 1 group cost/TCO program × ~6,925 employees + contingent |
| **Owner** | Uniform Program Manager / Finance (VS-17.4) / HR Finance / Analytics |
| **Participants** | Finance (VS-17.4), HR (VS-19/VS-102), Procurement (VS-03/VS-34), Analytics (VS-28), Shared Services (VS-72) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Build the TCO model: purchase (W4919), allowance (W4916), laundering (W4924), PPE (W4915/W4925), distribution (W4932), damage/loss (W4926), and end-of-life (W4934) — per employee/role/entity; reconcile allowance-paid vs uniforms-issued (W4916 double-dip) and the cross-entity chargeback (VS-72) | HR Finance / Program Manager / Analytics | Program Manager / CFO | Per program |
| 2 | Track spend vs budget & variance: actual cost/employee, cost/role, laundering cost, PPE cost, damage/loss rate, and vendor cost; flag variance and leakage (allowance double-dip, supplier price-creep, laundering loss) | Finance / Analytics / Program Manager | Program Manager | Monthly |
| 3 | Review & act: quarterly HR/finance review (links VS-33.2), reallocate budget, drive cost-out (vendor re-compete W4917, laundering-model optimization W4924, durability improvement W4919), and report to CHRO/CFO | Program Manager / HR Finance / Procurement | CHRO / CFO | Quarterly |

### System Touchpoints
- FP&A (VS-17.4/VS-33); HR/payroll (VS-19.2); procurement (VS-03/VS-34); shared services/chargeback (VS-72); analytics (VS-28)

### Pain Points / Risks
- **Cost-leakage risk**: Allowance double-dip, laundering loss, supplier creep → opex over-run; mitigated by the reconciliation + variance tracking
- **TCO-blindness risk**: Purchase-price focus ignoring laundering/PPE/replacement → wrong sourcing decision; mitigated by the full TCO model
- **Mis-allocation risk**: Cross-entity cost not fairly charged; mitigated by the VS-72 chargeback model

### Automation Opportunity
- TCO auto-model; allowance-vs-issue auto-recon; variance/leakage auto-alert; chargeback auto (VS-72)

### Controls
- CTL-739 (ensure controlled execution — Uniform/PPE Program Analytics, Compliance & Assurance (PA-169.3).)
- CTL-739: full TCO model; allowance vs issue reconciled; variance reviewed monthly; cross-entity chargeback correct

### Time Estimate
- ~initial TCO build 3–4 weeks; ~ongoing 2–4 staff-hrs/week; ~quarterly review half-day

### Cross-references
- links to VS-17.4/VS-33 (FP&A), VS-19.2 (payroll/allowance), VS-03/VS-34 (procurement), VS-72 (chargeback), VS-28 (analytics), W4916 (allowance), W4917/W4919 (vendor/design), W4924/W4926 (laundering/loss)

| **Frequency** | Continuous inventory + replenishment |

| **Owner** | Uniform Program Manager / Inventory (VS-05) / DC Ops (VS-04) / Store Ops (VS-07) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|

| 2 | Manage inventory & distribution: central holding + DC/site distribution, track stock-levels (VS-05/asset VS-35), replenish from supplier (W4917) on min-trigger, distribute to sites/onboarding, and manage sizing-mix (avoid over-stock of rare sizes) | Inventory / DC Ops / Store Ops / Supplier | Program Manager | Continuous |
