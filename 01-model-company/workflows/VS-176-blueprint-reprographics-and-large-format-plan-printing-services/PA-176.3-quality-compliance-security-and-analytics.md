## W5097. Print Quality, Color/Scale Accuracy & Dimensional Verification

| Field | Detail |
|---|---|
| **Trigger** | Each completed job (W5090/W5092); calibration cycle; defect/complaint |
| **Frequency** | Per job + calibration cycle |
| **Volume** | ~all jobs × QC |
| **Owner** | Reprographics Operator / Quality / Metrology (VS-115) |
| **Participants** | Operator, Quality, Metrology (VS-115), Store Services Lead |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Verify print quality: line definition, color accuracy (profile), no banding/bleed/smudge, media integrity, and finishing quality (binding/folding) | Operator / Quality | Store Services Lead | Per job |
| 2 | Verify scale/dimensional accuracy: print-to-scale correctness (critical for construction plans — a wrong scale is a jobsite error), using calibrated measurement (VS-115) | Operator / Metrology | Store Services Lead | Per job |
| 3 | Defect handling & rework: re-print defects (W5090), log defect rate, and feed calibration/maintenance (W5088) + analytics (W5099) | Operator / Quality | Store Services Lead | Per defect |

### System Touchpoints
- Quality/dimensional check; calibration/metrology (VS-115); print-management (W5086); analytics (W5099); maintenance (W5088)

### Pain Points / Risks
- **Scale-error risk**: Wrong print scale → jobsite/construction error (high-consequence for B2B); mitigated by dimensional verification (VS-115)
- **Defect-acceptance risk**: Defective print accepted → complaint/rework; mitigated by QC before release
- **Calibration-drift risk**: Color/scale drift unnoticed; mitigated by calibration cycle (W5088/VS-115)

### Automation Opportunity
- Auto-scale/color verification; defect-rate analytics; calibration-due auto-alert (W5088)

### Controls
- CTL-101 (ensure reprographics IP & file-handling control.)
- CTL-760: QC before release; scale verified (VS-115); calibration current (W5088)

### Time Estimate
- ~QC per job (minutes)

### Cross-references
- links to VS-115 (calibration); W5088 (maintenance), W5090 (printing), W5099 (analytics), W5102 (complaints)
