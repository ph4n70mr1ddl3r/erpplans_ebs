## W3097. Dark Store Order Wave Planning & Batch Release

| Field | Detail |
|---|---|
| **Trigger** | Continuous order intake; cut-off windows; batch release schedule |
| **Frequency** | 6–12 wave releases per day per dark store |
| **Volume** | ~50–400 orders per wave; ~1,000–5,000 lines/day per dark store |
| **Owner** | Dark Store Shift Supervisor |
| **Participants** | Dark Store Shift Supervisor, WMS, Pickers, Packers, Dispatch |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | WMS continuously aggregates eligible orders (links to VS-60) into a wave plan: group by SLA tier (same-day, next-day, BOPIS), cut-off, dispatch route/zone, and item overlap; respects promised time and rider/3PL capacity | WMS / Dark Store Shift Supervisor | Dark Store Shift Supervisor | Per wave (5–10 min) |
| 2 | Dark Store Shift Supervisor reviews proposed wave: volume vs. staffing, automation availability, hot-orders, known stockouts/substitutes; adjusts wave size and releases batch to pick | Dark Store Shift Supervisor | Dark Store Operations Manager | 5 min/wave |
| 3 | System reserves inventory against wave (atomic reservation to prevent oversell), prints pick labels / pushes to RF guns / dispatches goods-to-person bins; flags short-pick candidates for substitute approval | WMS | Dark Store Shift Supervisor | Automated |

### System Touchpoints
- WMS wave engine; OMS/order reservation (links to VS-60/VS-10; multi-org availability promising rides Oracle Global Order Promising — fit-gap D15); inventory (links to VS-05)

### Pain Points / Risks
- **Oversell risk**: Wave reserved against stale inventory; mitigated by atomic reservation and real-time sync to ecommerce (links to VS-10)


### Automation Opportunity
- System auto-route of "route/zone, and item overlap" (replaces manual Step 1).
- System auto-review of "reviews proposed wave" (replaces manual Step 2).
- System auto-generate of "prints pick labels / pushes to RF guns / dispatches goods-to-person bins" (replaces manual Step 3).

### Controls
- CTL-509 (ensure controlled execution — Micro-Fulfillment Daily Pick / Pack / Dispatch Operations (PA-93.2).)
- operational: atomic reservation and real-time sync to ecommerce (links to VS-10)

### Time Estimate
- 10–15 min/wave planning; 6–12 waves/day

## W3098. Multi-Order Batch Picking & RF/Automation-Guided Walk Optimization

| Field | Detail |
|---|---|
| **Trigger** | Wave released to floor |
| **Frequency** | Continuous during operating hours |
| **Volume** | Target ≥ 80 lines/picker-hour (manual) / ≥ 150 lines/picker-hour (MFC automation) |
| **Owner** | Dark Store Shift Supervisor |
| **Participants** | Pickers, Dark Store Shift Supervisor, Automation (if MFC) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Picker follows RF/automation-guided walk sequence (optimized for shortest path / goods-to-person bin delivery); scans bin and item at each pick face; confirms quantity against pick label/tote | Picker | Dark Store Shift Supervisor | Per wave |
| 2 | Multi-order batch pick: picker places each picked line into the correct customer tote/order partition (sort-while-picking); system validates scan-to-tote to prevent wrong-order placement | Picker | Dark Store Shift Supervisor | Per wave |
| 3 | On short-pick (stockout, damaged): picker marks reason code in WMS; system triggers substitute suggestion (links to VS-01 substitute logic) or short-ship / cancel per customer-eligible rule; for high-value/fragile, escalate to Supervisor | Picker / WMS | Dark Store Shift Supervisor | Per exception |

### System Touchpoints
- WMS pick engine; RF/voice/automation control; substitute logic (links to VS-01)

### Pain Points / Risks
- **Pick accuracy**: Mis-pick drives customer complaint and shrink; mitigated by scan-to-tote, weight-check at pack station, and picker accuracy KPI


### Automation Opportunity
- System auto-scan of "scans bin and item at each pick face" (replaces manual Step 1).
- System auto-validate of "validates scan-to-tote to prevent wrong-order placement" (replaces manual Step 2).
- System auto-log of "triggers substitute suggestion" (replaces manual Step 3).

### Controls
- CTL-77 (ensure dark-store order accuracy & dispatch control.)
- operational: scan-to-tote, weight-check at pack station, and picker accuracy KPI

### Time Estimate
- Per wave; ~20–40 min/wave depending on size

|---|---|---|---|---|

### Automation Opportunity
- System auto-scan of "scans order/tote at pack station" (replaces manual Step 1).
- System auto-validate of "check station validates packed weight vs." (replaces manual Step 2).
- System auto-log of "logged and fed back to picker/packer accuracy KPI" (replaces manual Step 3).

### Controls
- CTL-77 (ensure dark-store order accuracy & dispatch control.)
