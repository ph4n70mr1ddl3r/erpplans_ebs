## W4201. Booth/Stand Design, Build & Logistics

| Field | Detail |
|---|---|
| **Trigger** | Event confirmed (W4194); brand refresh |
| **Frequency** | Per event (flagship shows reusable) |
| **Volume** | Per-event booth/stand (national shows large; regional smaller) |
| **Owner** | Event Marketing Manager / Exhibit Designer |
| **Participants** | Brand (VS-14), Merchandising (VS-01), Procurement (VS-34), Logistics (VS-06), Vendor (co-exhibit) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Event Marketing/Designer design the booth/stand (layout, branding, product zones, demo area, meeting space, lead-capture station) aligned to brand (VS-14) and event objective (W4200) | Event Marketing Mgr / Designer / Brand | Event Marketing Mgr | Per event |
| 2 | Event Marketing/Procurement source build/fabrication, manage production timeline, and coordinate inbound logistics to the venue (shipping, customs for intl. shows, storage — links to VS-06/VS-34) | Event Marketing Mgr / Procurement / Logistics | Event Marketing Mgr | Per event |
| 3 | Event Marketing oversee installation/dressing at venue, resolve on-site issues, and capture build lessons for reuse (reusable modular booth inventory) | Event Marketing Mgr / Designer | Event Marketing Mgr | Per event |

### System Touchpoints
- Booth-design/build procurement (VS-34); brand (VS-14); logistics (VS-06); asset tracking (modular booth)

### Pain Points / Risks
- **Late-build risk**: Booth not ready at show open; mitigated by production timeline + contingency
- **Inbound-logistics risk**: Booth/product delayed in shipping/customs; mitigated by lead-time planning (VS-06/VS-87)

### Automation Opportunity
- Modular booth-inventory tracking; build-timeline/dependency tooling; 3D booth-preview

### Controls
- CTL-648 (ensure controlled execution — Exhibition & Trade-Show Operations (PA-139.2).)
- CTL-648: booth build on timeline; brand standards met (VS-14); asset tracked

### Time Estimate
- ~4–8 weeks per flagship show build; setup 1–3 days on-site

### Cross-references
- links to VS-14 (brand), VS-34 (procurement/build), VS-06 (logistics), VS-87 (intl. customs), W4207 (teardown/reuse)
